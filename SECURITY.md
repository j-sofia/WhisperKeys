# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use GitHub's
private vulnerability-reporting feature when it is enabled for this repository.
If it is unavailable, contact the repository owner privately through GitHub and
include enough detail to reproduce and assess the issue.

Reports should describe the affected version or commit, the impact, and
reproduction steps. You can expect an acknowledgement within a reasonable time
and coordinated disclosure after a fix is available.

## Scope

This application records microphone input and posts synthesized keyboard events.
Issues that could expose recorded audio, bypass macOS permissions, or send
unexpected keystrokes are especially important to report.
